# TylersUtilityBelt

This is a repo that I am using to create utilities for small tasks. The goal is to better learn coding, AI, GitHub, and more while doing it in a way that is fun and benefits current needs/wants I have. Please feel free to comment or post an issue (Advice and bug finds welcome).

## About

This repository serves as a collection of small utility scripts and tools that help with everyday tasks. Each utility is designed to be simple, focused, and educational.

## Structure

```
TylersUtilityBelt/
├── utilities/          # Collection of utility scripts
├── docs/              # Additional documentation
├── README.md          # This file
└── .gitignore         # Git ignore rules
```

## Getting Started

1. Clone this repository
2. Navigate to the utilities folder
3. Each utility has its own folder with documentation
