# Utilities

This directory contains various utility scripts and tools for small tasks.

## Available Utilities

- **example-utility**: A template/example showing how to structure utilities in this repository

## Adding a New Utility

To add a new utility:

1. Create a new folder with a descriptive name
2. Add a README.md explaining the utility
3. Include your code/scripts
4. Document how to use it

## Organization

Each utility should be self-contained in its own folder with:
- Clear documentation
- Any necessary code files
- Examples of usage
- List of dependencies (if any)

## Getting Help

If you need help with any utility, check its README.md file or open an issue on GitHub.
